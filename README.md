# Project 1 - Data Cleaning & Preparation

## How to run
1. Install Python 3.x.
2. Open this folder in VS Code or Jupyter.
3. Install dependencies:
   `pip install -r requirements.txt`
4. Run:
   `python clean_data.py`

## Files
- `raw_dataset.csv` - intentionally dirty source data
- `cleaned_dataset.csv` - cleaned and standardized output
- `clean_data.py` - reusable cleaning script
- `PROJECT_REPORT.md` - project documentation
- `requirements.txt` - Python dependencies
